# Локальные проверки

Python 3.10+ и стандартная библиотека. Сеть, ключи и дополнительные пакеты не нужны. Рабочий каталог в примерах: папка скилла `instagram-content`. Все команды читают UTF-8-файл и выводят JSON. Входной файл не изменяется. Вместо пути можно передать `-` для stdin. Код завершения 0 означает выполнение расчёта, а не качество текста; 2 означает ошибку входа.

```text
python scripts/content_tools.py hook hook.txt --wpm 150
python scripts/content_tools.py beats speech.txt --wpm 150 --target 30
python scripts/content_tools.py caption caption.txt --keywords "локальная модель,данные"
python scripts/content_tools.py style draft.txt
python scripts/content_tools.py clean draft.txt
python scripts/content_tools.py swipe captured.tsv
python scripts/content_tools.py profile profile.json
```

## Текст

`hook`: первая произносимая фраза. Длина, время и замечания; общего балла вирусности нет.

`beats`: только произносимая речь, одна смысловая реплика на строку. Не включай подписи кадров и режиссёрские указания. Темп 150 слов/мин является начальным редакторским допущением, не замером голоса. Скрипт не учитывает паузы и число произносимых слов внутри дат, сумм, аббревиатур. После получения аудио замерь фактическое время. `over_target_seconds` меньше нуля означает запас.

`caption`: считает символы Python Unicode (не визуальные глифы), слова, хештеги, наличие заданных фраз. `--preview 125` и `--max-chars 2200` являются настраиваемыми редакторскими ориентирами, а не проверенными текущими ограничениями Instagram. Реальная обрезка зависит от интерфейса.

`style`: перечисляет штампы из небольшого русского/английского словаря, длинные предложения, длинные тире и управляющие символы. Это неполный список подсказок для редактора. Невидимые символы бывают в обычном тексте и emoji; они не доказывают водяной знак ИИ.

`clean`: удаляет BOM и zero-width space в обычном тексте, заменяет отдельно стоящее длинное тире запятой. Сохраняет URL и фрагменты кода; не удаляет joiner внутри emoji. Результат содержит `text` и журнал `changes`. Перечитай грамматику, особенно замену тире; смысловую редактуру делает модель. Не подменяй исходник без запроса пользователя.

## Исследование

`swipe`: TSV, строка заголовков обязательна. Обязательные столбцы `account`, `median`, `views`, `hook`; рекомендуемые `url`, `observed_at`. Числа без сокращений и разделителей тысяч, дробная часть через точку. `median` больше нуля, `views` неотрицательное. Недоступные показатели не заполняй нулями. Медиану считай для сопоставимой выборки публикаций одного аккаунта, сохрани выборку и дату отдельно.

```tsv
account	median	views	hook	url	observed_at
demo-only	1000	3000	Что меняется при работе без облака?
```

Это синтетический пример, не найденный аккаунт. Результат: `ranked` с множителем views/median, `skipped` с причинами исключения строк, размер выборки. Пропущенные строки сообщи пользователю. Скрипт не посещает URL и всегда оставляет `source_verified: false`; реальные доказательства чтения источника хранятся отдельно. Нет автоматической классификации формул: сопоставление с hooks-ru.json делает модель по смыслу.

## Профиль

`profile`: JSON с объектом `criteria`. Ключи должны совпадать с `id` в [profile-rubric.json](profile-rubric.json). Каждое наблюдаемое поле: `{"score": 6, "evidence": "Что конкретно видно в профиле"}`. Пропущенные критерии остаются неизвестными; итог из 100 не выводится, пока не оценены все поля. Нулевой балл означает наблюдаемый недостаток, а не отсутствие доступа. Сумма весов 100. Это редакторская рубрика, не прогноз охвата.

## Перенос в другой чат

`python scripts/package.py --output КАТАЛОГ` собирает текстовый экспорт и ZIP из текущей версии скилла. Повторная сборка обновляет только три файла своего комплекта. Экспорт содержит инструкции, голос, формулы, рубрику и лицензию. Python-скрипты находятся в ZIP; текстовый экспорт сам по себе не запускает код. При отсутствии выполнения Python делай ручную проверку и честно обозначай её.
